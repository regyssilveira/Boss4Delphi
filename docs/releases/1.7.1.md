# Boss4D 1.7.1

Boss4D 1.7.1 is a focused fix release for Delphi IDE integration.

## Fixed

- The IDE Library Path integration now ignores missing
  `modules\dcu\<Platform>\Debug` directories instead of appending them to the
  global Delphi Library Path.
- Library Path deduplication now compares individual normalized path entries,
  avoiding false positives from partial string matches.

## Impact

This release prevents Boss4D from polluting Delphi's global Library Path with
nonexistent platform/configuration directories. Existing invalid entries already
present in the IDE settings are not removed automatically by this patch.

## Validation

- Delphi 13 IDE plugin package compile: passed.
- Windows DUnitX test executable compile: passed.
- Windows DUnitX suite execution: 332 of 334 tests passed. The two remaining
  failures are unrelated documentation fixture checks for missing executable
  examples.

## Upgrade Recommendation

Users running Boss4D 1.7.0 should upgrade to 1.7.1, especially when using IDE
registration or package installation flows that update Delphi Library Paths.
