# Boss4D 1.7.0

Boss4D 1.7.0 consolidates the component build and IDE-management work delivered
after 1.6.0. The release adds matrix-aware incremental and parallel builds,
runtime/design-time package planning, isolated IDE profiles, transactional
registration and rollback, a guided GUI, Registry governance, and native
macOS arm64 distribution.

## Download

The authoritative publication is the
[GitHub release](https://github.com/regyssilveira/Boss4Delphi/releases/tag/v1.7.0).
It contains:

- `Boss4D_Setup.exe` and `boss4d-windows.zip`;
- `boss4d-linux-x86_64.tar.gz`;
- `boss4d-macos-arm64.tar.gz`;
- the immutable `boss4d-1.7.0.b4dpkg`;
- `SHA256SUMS.txt` and `artifact-matrix.json`;
- CycloneDX 1.7 and SPDX 2.3 SBOMs with in-toto statements;
- GitHub OIDC build attestations.

Always verify a download against `SHA256SUMS.txt` before installation.

## Certified evidence

- 332 DUnitX tests on Delphi 13 for Win32 and Win64;
- 73 FPCUnit tests and real CLI smoke tests on Linux and macOS;
- real IDE plugin builds with Delphi 10 Seattle, 11, 12, and 13;
- Delphi 10.1 Berlin source compatibility through the shared legacy profile;
- successful Windows installer, Linux archive, macOS archive, immutable
  package, checksum, attestation, and publication jobs;
- Sonar Quality Gate with zero new violations and 0% new duplication.

Delphi 10 Seattle and Delphi 13 are required by the local release gate.
Delphi 10.1, 11, and 12 are compiled when installed; the certified 1.7.0
runner also had Delphi 11 and 12.

## Registry status

The GitHub release and self-update channel publish 1.7.0. The reviewed public
Registry entry remains on the signed 1.6.0 package until the detached OpenPGP
signature required by Registry v2 is published. Registry metadata must never
claim an unsigned artifact or alter the immutable 1.6.0 record.

## CLI help

Use `boss4d help` on Windows and `boss4d help`, `boss4d -h`, or
`boss4d --help` on FPC hosts. The help banner reports version 1.7.0 and lists
only commands implemented by that native CLI.
