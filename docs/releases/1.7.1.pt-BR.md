# Boss4D 1.7.1

O Boss4D 1.7.1 é uma release corretiva focada na integração com a IDE do
Delphi.

## Corrigido

- A integração com o Library Path da IDE agora ignora diretórios
  `modules\dcu\<Platform>\Debug` inexistentes em vez de adicioná-los ao
  Library Path global do Delphi.
- A deduplicação do Library Path agora compara entradas individuais
  normalizadas, evitando falsos positivos por comparação parcial de texto.

## Impacto

Esta release evita que o Boss4D suje o Library Path global do Delphi com
diretórios de plataforma/configuração que não existem. Entradas inválidas já
presentes nas configurações da IDE não são removidas automaticamente por este
patch.

## Validação

- Compilação do pacote do plugin da IDE para Delphi 13: passou.
- Compilação do executável de testes DUnitX no Windows: passou.
- Execução da suíte DUnitX no Windows: 332 de 334 testes passaram. As duas
  falhas restantes são verificações de fixtures de documentação ausentes e não
  relacionadas a esta correção.

## Recomendação de Atualização

Usuários da versão 1.7.0 devem atualizar para a 1.7.1, principalmente quando
usarem fluxos de registro na IDE ou instalação de pacotes que atualizam Library
Paths do Delphi.
